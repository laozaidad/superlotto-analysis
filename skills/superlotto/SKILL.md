# 大乐透选号分析

使用本 Skill 的脚本完成数据校验、特征计算和组合生成，不凭语言模型直觉编造号码。内部标识为 `superlotto`，显示名称为“大乐透选号分析”。

## 决策边界

- 适用于前区35选5、后区12选2；双色球33选6、16选1不能套用此规则。
- 固定历史下限为2013-01-01（含当天，对应13001起）；不得为了增加样本而引入更早记录。
- 默认输出是覆盖设计，不是中奖预测。保留 `prediction_gate=CLOSED`，不把冷热、遗漏或多样性分数换成中奖置信度。
- 跨期独立假设不等于同区号码或同期开奖的多组号码相互独立。固定完整组合全中概率在各区均匀且两区独立假设下为 `1 / 21,425,712`。
- 大数定律不要求冷号补齐；均值回归不意味着下一期反向补偿。不能用“强胆、必出、最稳、保底、稳赚”等说法解释结果。

## 数据优先与截断

先确认目标期号、用户数据路径、组数和随机种子。目标期号使用用户指定的五位字符串；下文以 `TARGET` 占位，不绑定某个期次。已有明确上下文时直接沿用，缺少目标期号时询问，不猜最新期次。随机种子默认0，仅用于复现。

1. 有用户指定 CSV：读取该文件，不替换、不自动联网更新、不混入其它数据。
2. 指定路径不存在：运行入口默认从13001起获取 [500网大乐透](https://datachart.500.com/dlt/) 的历史数据，校验后保存 CSV 和来源元数据。独立抓取的 `--start` 早于13001时拒绝；离线HTML也执行历史下限过滤。
3. 已有文件无效、网页不可访问或页面结构不符：报错并停止。可请用户提供符合格式的 CSV，或保存的500网历史页 HTML；不回退到内置历史样本，也不伪造缺失期次。

生成目标期只使用2013-01-01起且 `id < target` 的记录。本地CSV可包含更早记录，但它们只参与输入审计，不参与频率、遗漏、上期重号、历史完整组合排除、形态或选号。同一期及未来记录也不得参与模型；不能从2012年及以前借用“上期”。报告实际训练首末期、条数，以及旧记录和未来记录的排除情况。筛选后无有效历史时停止，不退回旧范围。

首次接入数据或排查错误时读取 [数据格式与获取边界](references/data-schema.md)。500网是第三方来源，不是官方核验；只有请求成功不代表历史完整。数据不足100期、未覆盖目标前一期或完整性未证实时，明确提示局限，不隐去陈旧状态。

## 执行

运行环境为 Python 3.10+，运行脚本只依赖标准库。

先将环境变量 `TARGET` 设置为用户指定的五位目标期号，再从仓库根目录运行：

```bash
python3 skills/superlotto/scripts/run_skill.py \
  --data data/numbers.csv \
  --target "${TARGET:?请先设置用户指定的五位目标期号}" \
  --seed 0 \
  --groups 5 \
  --output outputs/result.json
```

已安装 Skill 时，将脚本路径换成该 Skill 目录内 `scripts/run_skill.py` 的实际路径。数据和输出放在用户工作目录，不写入 Skill 安装目录。

- 默认 `coverage`：1–6组。左右区分别分散，优先实现号码并集覆盖，再从固定256份候选分区中选择形态多样性较高者。
- `--mode uniform`：同组数均匀抽样对照。
- `--groups 1`：只输出一组。默认5组是演示规模，不是建议多买。
- `--seed`：复现用参数，不是选号秘诀。比较模式时固定数据、种子和组数，不反复换种子挑“最好看”的结果再声称预测优势。
- `--output`：结果路径已存在时拒绝覆盖，改用新的输出路径。入口没有 `--refresh` 或 `--overwrite`；显式刷新数据使用独立抓取脚本，不改变已有文件优先的规则。

完整算法、分箱和概率边界见 [方法说明](references/methodology.md)。如果用户只要求生成号码，不必重新做整个研究回测。

## 输出与核验

以实际脚本 JSON 为准，交付：

- 目标期、使用数据截止期、来源及数据质量警告。
- 每组 Left / Right，按升序两位数展示；不设置没有证据的概率排名。
- 用户需要时展示七类特征、号码并集和组间交集；三连号必须计2对相邻连号。
- 模型版本、种子和数据 SHA-256，供复现；本地路径不作为公开分享内容。
- 明确“仅作统计参考与组合设计，未证明优于随机，不构成购彩建议”。

至少核对：每组数量/范围/区内唯一；完整组合之间不重复；coverage 模式的区间组间不重号；历史起点不早于2013-01-01且训练截止期严格早于目标；概率事件明确。历史完整组合重复只警告，不把真实记录擅自删除。

当前生成器仅排除有效分析范围内已见完整组合，是自定义生成约束，不代表开奖不能再次出现相同组合，也不提升单组概率。

## 进一步研究

需要新增预测权重或宣称统计优势时，先阅读方法说明中的验证准入规则。先前包含2013年以前数据的回测不构成本范围的验证；新回测同样不得越过历史下限。冻结模型后使用真正新增的数据，预先确定指标、样本量和多重比较处理。反复查看过的历史回测只能作为探索，不得称为独立确认。没有对应实验数据时保持均匀基准，不为满足“推演”措辞虚构优势。
