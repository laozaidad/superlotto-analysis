# 方法说明

## 可靠性与概率基线

可靠性是可审计、可复现、定义明确、无未来数据泄漏，不是稳定中奖或保证收益。默认 `prediction_gate=CLOSED`、`predictive_advantage_claim=false`。历史特征没有被当作已验证的预测权重。

所有统计和生成固定使用2023-01-01起（含当天，对应23001起）、严格早于用户指定目标期的记录。原文件中更早的记录只做输入审计，不参与频率、遗漏、上期重号、历史完整组合排除、形态评分或选号；不从范围外借用上期，不为增加样本而放宽下限。

假设每区合法组合均匀、左右区独立、跨期独立：

- 单个Left号码的每期入选概率为 `5/35=1/7`，Right为 `2/12=1/6`。
- 单个完整组合概率为 `1/[C(35,5)×C(12,2)]=1/21,425,712`。
- 同一期固定的 `m` 个不同完整组合，全中事件互斥，并集概率为 `m/21,425,712`；这不是任意奖率。

区内无放回抽样使号码相关，多组组合又共享一次开奖，不能将它们当成彼此独立的重复试验。

大数定律说明长期相对频率趋向概率，不要求短期补齐，也不保证累计绝对偏差缩小。均值回归说明从噪声中筛出的极端表现往往不持续，不构成冷号反弹或热号必降的补偿机制。

## 特征口径

| 特征 | 定义 | 不应推导的结论 |
|---|---|---|
| 奇偶比 | 奇数数目:偶数数目 | 均衡组合中的某一注更可能 |
| 大小比 | Left小1–17/大18–35；Right小1–6/大7–12 | 上期偏大所以下期必须偏小 |
| 和值 | 区内号码之和，理论均值Left90、Right13 | 下期必须向均值修复 |
| 跨度 | 最大号减最小号 | 特定跨度能保证更高命中 |
| 连号 | 排序后差1的相邻对数；三连计2对，另报最大连续段 | 连号或三连号应自动杀号 |
| 重号 | 与上一期同区集合的交集大小 | 上期出现过的号码本期更不可能 |
| 冷热与遗漏 | 给定历史窗口频数、距最近出现期数 | 久未出现意味着下期更容易出 |

Left大小池是17/18个，不是精确一半。重号不等于不同示例组之间的号码重叠，也不等于历史完整组合重复。

冷热默认窗口为100期，以实际可用 `n` 计算：

```text
p = k / M
expected = n * p
sd = sqrt(n * p * (1 - p))
z = (count - expected) / sd
z >= 1：热；z <= -1：冷；其余：温
```

这是相对均匀基准的一倍标准差描述，不是显著性检验或预测置信度。窗口和遗漏只在2023年以来的有效历史中计算；遗漏取本范围内最近一次出现，最新出现为0，没有出现过的号码用删失标记说明不确定性。早于范围的出现不能解除删失或缩短遗漏。

## 特征类别不等于具体组合

组合数更大的特征类别较常见，不代表该类别中某一个完整组合概率更高。例：Right和值9–16涵盖38/66，即57.5758%的合法后区组合。硬性只保留这一范围会排除42.4242%的可能结果，而不会提高已选固定完整组合的概率。

和值、大小、跨度等特征相关；不得相乘各自边际概率作为组合置信度。默认没有奇偶平衡、和值限制、三区全覆盖、冷热混搭或禁止三连等硬过滤。

## 组合生成

### uniform

每次分别均匀抽取合法Left与Right。完整组不得在本次结果中重复，并仅排除有效分析范围内已见历史完整组。

历史排除是本模型保留的自定义生成约束，不是开奖规则。历史可以再次出现同样组合；排除它们不增加单组概率。

### coverage

支持1–6组，受12个Right号码分配为不相交2码组限制。

1. 固定种子，将1–35和1–12各自随机打乱。
2. 顺序分成每组5个Left和2个Right，保证两区组间各不重号。
3. 生成256份合法候选分区；按形态档位的不同取值数选最多样的一份，平分取第一份。

每区使用6个档位：奇数个数、小号个数、和值档、跨度档、相邻连号对数、上期重号数。Left和值档为 `sum//15`、跨度档 `span//7`；Right分别为 `sum//5`、`span//3`；其它档位用原整数值。所有档位不同取值数相加得到 `diversity_score`。

该分数只表达多组形态多样性，不是中奖率或置信度。冷热权重为0；这些分箱也不是由历史拟合得到的预测参数。候选分区搜索没有声称形态分数的全局最优。

5组coverage会覆盖25个Left、10个Right，达到这两个号码并集规模的上限。它不要求每组看起来均衡，可以包含全奇、全大等合法形态。默认5组只是展示规模，不建议因此增加投入。

### 条件融合研究

独立研究入口提供条件成绩学习、历史排名相似性软降权与固定规格池。默认模型的 `groups` 与研究的 `pool_size` 不混用，二者均保持预测准入关闭。数学细节、已有探索证据与留档要求见 [条件融合研究](research.md)。

## 评价覆盖时定义事件

号码并集更大不自动意味着每种奖级概率都更大。使用诸如“至少一组Left命中至少3个且同组Right命中至少1个”这样的明确事件，且与未经核验的奖级、奖金区分。

对于上述事件，若各组Left互不相交，那么两组同时各命中至少3个需至少6个不同开奖号码，而Left实际只有5个。因此各组事件互斥，可达到组数乘单组事件概率的并集上界。这一证明不依赖冷热或形态分数，也不能推广为任意奖或收益最优。

单组概率或稀有事件能精确枚举时优先精确计算。若使用蒙特卡洛，保留种子、模拟次数和区间；同一批模拟开奖比较两组策略，应使用配对差值而不是独立比例标准误。一个固定随机组合对照不代表所有随机组合的平均表现。

本Skill没有当期官方奖级、奖金或实际投注销量数据，不输出返奖率、奖金期望、盈利或避分奖优势。

## 预测权重的准入

实验权重可以在明确隔离的研究入口生成候选，但在被称为经验证预测能力前必须单独验证，不能因一次命中而改变结论：

1. 冻结模型、候选策略数、主要指标、最小实际重要提升、检验方向与结束样本量。
2. 按要使用的检验与数据生成假设计算功效；统计功效不是下一期命中率，也不计算循环的“观察效应事后功效”。
3. 历史回测严格逐期只用2023-01-01起且此前的记录；已反复看过的数据只作探索性分析。
4. 真正确认使用冻结之后新增的数据，处理多重比较并报告效应区间和时间段稳定性。
5. 边际概率模型同时报告Brier或校准，不给只排序的策略伪造概率；未通过门槛保持均匀基准。

未发现优势不证明所有可能策略都无效；它要求保留不确定性，而不是输出虚假的预测结论。

先前包含更早年份的回测和功效结果不能直接视为本范围的验证。范围调整后，应重新计算样本量、指标和相应不确定性；仅重新裁剪已查看的历史仍不构成新的独立确认。

## 参考与取舍

- [SSQ Analysis](https://github.com/TouKenAI/ssq-analysis)：借鉴单一数据源、离线可复现和独立复核；不套用双色球33选6+16选1的规则。
- [Daletou Analysis](https://github.com/TouKenAI/daletou-analysis)：借鉴指标口径与覆盖设计；不采用固定强胆、后区和值硬过滤或未经验证的收益结论。
- [Statistical Power](https://github.com/K-Dense-AI/scientific-agent-skills/tree/main/skills/statistical-power)：参考其冻结假设、功效敏感性、多重比较与避免事后功效的原则。
